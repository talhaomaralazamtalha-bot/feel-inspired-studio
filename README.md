I have attached a video showing the UI/UX style and interaction design I want for this portfolio.

Watch and analyze the entire attached video before writing the website code.

Use the video as the primary visual and interaction reference.

Analyze:

Overall visual style

Layout structure

Typography

Spacing

Color palette

Background treatment

Navigation behavior

Hero section composition

Scroll behavior

Section transitions

Animation timing

Hover effects

Cursor interactions

Text animations

Project presentation

Cards and borders

Image/video usage

Timeline/visual storytelling

Mobile/responsive behavior if shown

Overall mood and visual hierarchy

VERY IMPORTANT

Do not simply copy the exact content from the video.

Instead:

Recreate the design language, interaction patterns, animation philosophy and overall visual experience of the reference video, but apply them to my personal portfolio and my own content.

Think of it as:

Reference video = UI/UX direction

My portfolio brief = content + information architecture

The final website should feel inspired by the reference video while still being an original portfolio for Didarul Azam Mahi.

If a specific effect from the video cannot be reproduced exactly, create the closest high-quality implementation using modern React/Next.js techniques.

Do not reduce the design to a generic template.

DESIGN PRIORITY

Prioritize the following in this order:

Match the overall feel of the reference video

Reproduce the important interactions and transitions

Maintain excellent typography and spacing

Apply the visual system consistently across every section

Integrate my personal story and projects naturally

Maintain performance and accessibility

Ensure excellent mobile responsiveness

The website should feel like a designed digital experience, not a collection of sections.

REFERENCE-FIRST IMPLEMENTATION

Before coding:

Watch the complete video.

Identify the major UI sections.

Identify recurring visual patterns.

Identify animation/transition patterns.

Identify navigation behavior.

Identify how content enters/leaves the viewport.

Identify how projects are presented.

Identify any unusual interactions that make the design distinctive.

Translate those patterns into reusable React components.

Then combine them with the portfolio content specification below.

Do not start coding after watching only the first few seconds of the video.
